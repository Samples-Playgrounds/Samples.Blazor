## Sample 1: Basic YARP with Blazor Server

### Overview
A simple reverse proxy setup where YARP forwards incoming requests to a backend Blazor Server app.

### Project Structure
```
BasicYarpSolution/
├── YarpProxy/                 # YARP reverse proxy project
├── BlazorBackend/             # Blazor Server backend
└── README.md
```

### YARP Proxy Project (`YarpProxy`)

**Program.cs**
```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddReverseProxy().LoadFromConfig(builder.Configuration.GetSection("ReverseProxy"));

var app = builder.Build();

app.UseRouting();
app.UseEndpoints(endpoints =>
{
    endpoints.MapReverseProxy();
});

app.Run();
```

**appsettings.json**
```json
{
  "ReverseProxy": {
    "Routes": {
      "blazor-route": {
        "ClusterId": "blazor-cluster",
        "Match": {
          "Path": "{**catch-all}"
        }
      }
    },
    "Clusters": {
      "blazor-cluster": {
        "Destinations": {
          "destination1": {
            "Address": "https://localhost:5001"
          }
        }
      }
    }
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information"
    }
  }
}
```

### Blazor Backend Project (`BlazorBackend`)

**Program.cs**
```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddRazorPages();
builder.Services.AddServerSideBlazor();

var app = builder.Build();

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();

app.MapBlazorHub();
app.MapFallbackToPage("/_Host");

app.Run();
```

### Running the Solution
1. Start the Blazor Backend (`dotnet run` in `BlazorBackend` folder).
2. Start the YARP Proxy (`dotnet run` in `YarpProxy` folder).
3. Access the app via the YARP URL, e.g., `https://localhost:5000`.

## Sample 2: Advanced YARP with Blazor Server

### Overview
An advanced configuration featuring multiple routes, authentication, header transformation, and load balancing across two Blazor instances.

### Project Structure
```
AdvancedYarpSolution/
├── YarpProxy/                      # YARP proxy with advanced config
├── BlazorBackend1/                 # Blazor Server backend 1
├── BlazorBackend2/                 # Blazor Server backend 2
└── README.md
```

### YARP Proxy Project (`YarpProxy`)

**Program.cs**
```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddReverseProxy()
    .LoadFromConfig(builder.Configuration.GetSection("ReverseProxy"))
    .AddTransforms(transformBuilderContext =>
    {
        transformBuilderContext.AddRequestTransform(transformContext =>
        {
            transformContext.ProxyRequest.Headers.Add("X-Forwarded-For", transformContext.HttpContext.Connection.RemoteIpAddress?.ToString());
            return ValueTask.CompletedTask;
        });
    });

var app = builder.Build();

app.UseHttpsRedirection();
app.UseRouting();
app.UseAuthentication();
app.UseAuthorization();
app.UseEndpoints(endpoints => endpoints.MapReverseProxy());

app.Run();
```

**appsettings.json**
```json
{
  "ReverseProxy": {
    "Routes": {
      "main-app": {
        "ClusterId": "main-cluster",
        "Match": {
          "Path": "/"
        },
        "Transforms": [
          { "PathRemovePrefix": "/" }
        ]
      },
      "api-app": {
        "ClusterId": "api-cluster",
        "Match": {
          "Path": "/api/{**remainder}"
        },
        "Transforms": [
          { "PathRemovePrefix": "/api" }
        ]
      }
    },
    "Clusters": {
      "main-cluster": {
        "LoadBalancingPolicy": "RoundRobin",
        "HealthCheck": {
          "Active": {
            "Enabled": true,
            "Interval": "00:00:10",
            "Timeout": "00:00:05",
            "Policy": "ConsecutiveFailures",
            "Path": "/health"
          }
        },
        "Destinations": {
          "destination1": {
            "Address": "https://localhost:5001",
            "Health": {
              "Active": "https://localhost:5001/health"
            }
          },
          "destination2": {
            "Address": "https://localhost:5002",
            "Health": {
              "Active": "https://localhost:5002/health"
            }
          }
        }
      },
      "api-cluster": {
        "Destinations": {
          "api-destination": {
            "Address": "https://localhost:6000"
          }
        }
      }
    }
  }
}
```

### Blazor Backend Projects

**BlazorBackend1 & BlazorBackend2**

  - Standard Blazor Server setup with `AddServerSideBlazor()`
  - `/health` endpoint for health checks:
    ```csharp

    ```
  - Optional: Add identity or authentication if needed.

### Running the Solution
1. Start both Blazor backends (`BlazorBackend1`, `BlazorBackend2`).
2. Start the API backend (if using).
3. Start the YARP proxy.
4. Access via the proxy URL, e.g., `https://localhost:5000`.
